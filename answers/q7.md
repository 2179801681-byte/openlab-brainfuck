# 第 7 题：奇怪的书

## 第一页

程序先输入一个字符。设该字符的 ASCII 十进制值为 `x`：

```text
,[
>+
<-
]
>-.
```

循环每次将第 1 个单元加 1、将第 0 个单元减 1，直到第 0 个单元为 0。
因此循环结束时，第 1 个单元的值为 `x`。接着 `>-` 移到第 1 个单元并减 1，
`.` 输出该数值对应的字符。

输出值为 `(x - 1) mod 256`。例如：

- 输入 `B(66)`，输出 `A(65)`。
- 输入 `A(65)`，输出 `@(64)`。
- 输入 `NUL(0)` 时，循环不执行，第 1 个单元从 0 减 1 后溢出为 255。
  255 不属于标准 ASCII 范围，无法指定唯一的标准 ASCII 字符。

## 第二页

```text
++++++++++
[
>++++++++
>++++++++
<<-
]
>-.
>.
```

第 0 个单元先加到 10，循环执行 10 次。每次循环使第 1、2 个单元各加 8，
并使第 0 个单元减 1。循环结束后，三个单元分别为 `0`、`80`、`80`。

随后第 1 个单元减 1，输出 `79` 对应的 `O`；再移到第 2 个单元，
输出 `80` 对应的 `P`。因此输出为：

```text
OP
```

## 第三页

程序：

```text
,>,[<+>-]<.
```

第一个 `,` 将第一个字符的值写入第 0 个单元；`>` 移到第 1 个单元，
第二个 `,` 读入第二个字符。循环 `[<+>-]` 每次把第 1 个单元减 1、
第 0 个单元加 1，直到第 1 个单元为 0。最后 `<.` 输出第 0 个单元的值。

例如输入 `A` 和 `!`，数值为 `65 + 33 = 98`，输出 `b`。

题目规定单元值为 0–255，所以结果是 `(x + y) mod 256`。对标准 ASCII 输入，
当结果为 0–127 时，它对应标准 ASCII 中的字符或控制字符；当结果为 128–254 时，
它不在标准 ASCII 范围内，实际显示取决于运行环境的编码。题目假设所有 ASCII
字符均可输入，包括 `NUL(0)`，上述程序对此也成立。
